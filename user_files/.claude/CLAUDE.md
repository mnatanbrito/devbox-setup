# General

## Writing

Whenever writing any technical documents, specs, plans, reports, etc., use the ASD-STE100 Simplified Technical English (STE) to simplify the writing.

# Github

Whenever interacting with a git repo, you MUST use the `gh` command line.

## Pull request (PR) creation

ALWAYS create new PRs in draft mode.

ALWAYS ask before committing changes to the remote repo.

NEVER merge a temporary branch directly into the main branch locally. ALWAYS create PRs.

## Committing code

NEVER append any indication that the PR was created using coding agents in the PR description.
